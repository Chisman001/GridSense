# 1. Design Philosophy

GridSense AI is an AI-powered Energy Decision Support Platform.

The interface should prioritize decisions over data.

Every page should answer one question:

"What should the user do next?"

The interface should feel:

• Clean

• Modern

• Fast

• Professional

• Trustworthy

• Data-driven

The application should avoid visual clutter and focus on actionable insights.

# 2. Design System

Design Language

Inspired by

- Vercel

- Stripe
